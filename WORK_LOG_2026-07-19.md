## 3. Images are resized, not rejected — `src/middlewares/process_upload.js` (new)

You asked for oversized photos to be made to fit rather than refused. Images are
re-encoded to fit within 2560×2560 as webp at quality 82, so the broker never
has to think about file size.

Three correctness details worth keeping:

```js
// Read into a buffer rather than handing sharp the path: libvips keeps the
// input file open, which makes the temp file undeletable on Windows and
// leaked one copy of every upload.
const input = await fs.readFile(file.path);

await sharp(input, { limitInputPixels: 100_000_000 })
  .rotate()   // must precede resize — sharp drops the EXIF orientation flag
  .resize({ width: 2560, height: 2560, fit: "inside", withoutEnlargement: true })
  .webp({ quality: 82 })
  .toFile(target);
```

- **`.rotate()` before `.resize()`** or portrait photos come out sideways.
- **Pass a Buffer, not a path.** Handing sharp a path leaks the temp file — this
  was a real ~30MB-per-batch leak, made invisible by a `removeQuietly` helper
  that swallowed the `unlink` failure. Cleanup failures now log.
- `clearTempDir()` runs on boot to sweep anything left by a crash.

Sharp also **strips EXIF**, including GPS. That is the desired outcome for a
public listing site, but worth knowing it happens.

## 4. Security fix — path traversal in delete

```js
fs.rmSync("public/" + filename)   // ← before
```

`filename = "../../.env"` escaped the upload directory. Fixed with `basename`
plus a resolved-path check that the target is still inside `UPLOAD_DIR`.
Verified `../../.env` no longer escapes.

Also: `split("\\")` on upload paths was Windows-only and would have returned the
full path on Linux/Docker → replaced with `path.basename`.

## 6. A workflow note, not a code problem

Your existing listing photos are **WhatsApp-compressed at 1280×960**. The
pipeline can't recover detail that was thrown away before upload — resizing only
ever shrinks. If photo quality matters, the fix is to get originals off the
camera rather than via WhatsApp. The 2560px ceiling is generous enough that real
originals will come through well.
